# Où est le suspect ?

A French prepositions detective game set in Bellevue. Listen to *la centrale*, then tap where the suspect is hiding: *devant la banque*, *sur le toit du musée*, *sous l'arbre*…

Play: https://churchtim8-cpu.github.io/ou-est-le-suspect/

- `?level=easy|medium` sets the level, `?case=c1-3` opens one case, `?gfx=light` for weak devices.
- `npm run dev` to play locally, `npm run check` and `npm run test:e2e` before pushing.
